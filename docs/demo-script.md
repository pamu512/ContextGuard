# Demo script (< 3 minutes)

1. **Hook (15s)** — “Dropping a column shouldn’t be a 2am incident. ContextGuard uses DataHub context to show blast radius before you merge.”
2. **Connect (20s)** — Open the app, enable Demo mode (or show live MCP connect).
3. **Select (20s)** — Pick `ecommerce.public.orders`.
4. **Analyze (40s)** — Enter `DROP COLUMN amount`. Show risk score, downstream Revenue dashboard, owners, unknowns.
5. **Artifacts (45s)** — Flip through report, compatibility SQL view, dbt tests, owner message. Download ZIP.
6. **Contrast (20s)** — Run the safe `status` type change example; show lower risk / empty dependents.
7. **Close (20s)** — “Read → reason → act on DataHub metadata. Judges can reproduce from `examples/` without credentials.”

Record with public YouTube/Vimeo visibility. Keep UI zoom comfortable; avoid showing real tokens.
